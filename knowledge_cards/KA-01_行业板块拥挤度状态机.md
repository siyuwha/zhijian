# 证据卡 KA-01：行业/板块拥挤度状态机 (Sector Crowding State Machine)

## 1. 名称与类别
- **资产名称**：行业/板块拥挤度状态机 (Sector Crowding State Machine)
- **统一认知分类**：`State`（状态层）+ `Derived Feature`（底层特征）+ `Rule`（状态跃迁约束）

## 2. 原始来源与可定位证据
- **原始文件**：`\\Fn-evo2-xh\文件中转站\盘股证券交易助手 — 产品说明书（09070030）.pdf`
- **定位页码**：第 21-22 页（第 5.3.2 节“拥挤度方法论”）、第 45 页（第 12 章术语定义）
- **核心文本摘录**：
  > “拥挤度衡量板块交易热度相对‘自身历史 + 全市场横向’的极端程度，设计意图是把策略回撤控制在可接受范围（不在过热时追高、在冰点区域提示布局机会）……多因子合成、双重参照（时间序列百分位 + 横截面排名）、状态机分档（带磁滞与确认/冷却机制）、权重管理、决策矩阵。”

## 3. 解决的实际问题
- 避免在市场主流板块极度亢奋、成交过度拥挤的末期盲目追高站岗；
- 在无人问津的极度冰点低迷区域提示潜在反转布局机会；
- 解决单一指标临界点上下反复横跳（震荡抖动）的问题。

## 4. 输入数据与数据质量要求
- **输入维度**：板块成交额占比、板块换手率、板块内创新高股票占比、均线多头排列比例、两融杠杆资金流入占比、板块指数与均线乖离率；
- **质量要求**：板块成分股数据必须完整覆盖；若部分成分股停牌或缺失，按剩余成分股流通市值重新归一化加权；不可偷填 0。

## 5. 公式、算法或明确逻辑
1. **单因子标准化**：
   - 时间序列分位：$P_{ts}(f_i) = \text{PercentileRank}_{120d}(f_i)$（相对自身历史 120 日）
   - 横截面分位：$P_{cs}(f_i) = \text{Rank}_{market}(f_i) / N_{sectors}$（相对全市场行业）
   - 因子得分：$S(f_i) = 0.5 \times P_{ts}(f_i) + 0.5 \times P_{cs}(f_i)$
2. **多因子合成拥挤度指数**：
   $$\text{CrowdingIndex} = \sum_{i=1}^{M} w_i \cdot S(f_i), \quad \sum w_i = 1.0, \quad \max(w_i) \le 0.35$$
3. **状态机分档与磁滞跃迁（Hysteresis State Machine）**：
   - 档位：`EXTREME_COLD`（极度低迷） / `COLD`（冷门） / `NORMAL`（正常） / `ACTIVE`（活跃） / `CROWDED`（拥挤） / `OVERHEATED`（极度过热）
   - 上穿跃迁：例如从 NORMAL 升级为 CROWDED 需要指标 $> 80$ 且持续 2 个交易日（确认期）；
   - 下穿回退：从 CROWDED 回退到 NORMAL 必须跌破 $72$（磁滞缓冲区 8%），且脱离过热后进入 3 日冷却期（Cooldown）。

## 6. 输出与消费方
- **输出**：板块拥挤度得分（0~100）、当前状态标签（State Enum）、持续天数、确认状态；
- **消费方**：M1 复盘板块报告、M2 盘前简报主线推演、M6 选股/开仓仓位上限约束 Gate。

## 7. 参数、阈值、默认值及来源
- **盘股说明书脱敏说明**：说明书遵循脱敏原则，未披露固定数值；
- **经验推荐默认值**：120日滚动回看窗口、上穿门槛 80、回退门槛 72、确认期 2日、冷却期 3日、单因子权重上限 0.35。

## 8. 数据依赖、频率与时点一致性
- **频率**：日频（收盘 15:00 结算后计算一次；盘中 14:30 仅供试算）；
- **时点一致性**：必须严格基于当日或历史已发生行情，严禁使用次日数据。

## 9. 可复现性与复现缺口
- **复现性**：**部分可复现（Partial）**；
- **缺口**：说明书中因子权重被脱敏；A股申万或东财行业分类的历史成分股变迁需要历史板块映射字典。

## 10. 历史验证证据
- **说明书声称**：具备有效性监控，因子权重按滚动 IC 与回撤控制效果定期刷新；
- **代码库实况**：当前代码库无任何该模块代码或回测日志。

## 11. 历史验证 / Falsification 方法
- **回测设计**：在全A历史数据（2020~2026）上测试，当板块处于 `OVERHEATED` 状态时，买入该板块股票在随后 5日、10日、20日的胜率、最大回撤与超额收益分布；
- **证伪条件**：若处于 `OVERHEATED` 状态下的板块随后 20 日表现显著优于全市场中位数（无显著均值回归或杀跌），则拥挤度防高位站岗假设被证伪。

## 12. 适用前提与失效条件
- **适用前提**：板块具有充足的流动性与机构/游资博弈深度（非极度冷门的几只微盘股集合）；
- **失效条件**：发生超预期特大产业革命（如 2023 年初 AI 主线浪潮），极度拥挤可维持数月并持续加速突破；政策强行托底或外部不可抗力。

## 13. 潜在偏误与风险
- **过拟合与主观阈值**：80/72 阈值可能在牛熊周期中表现不一；
- **幸存者偏差**：成分股剔除退市股带来的后见之明。

## 14. 初步迁移建议与风险
- **迁移分类**：`Adapt`（适配引入，但须前置数据准入）；
- **架构落点**：作为独立的 State Machine 挂载在 M1 收盘事实抽取与 M6 风控 Gate 之间；
- **风险防范**：初始阶段不直接硬拦截下单，仅输出为 `Derived Feature` 与 `State` 供审计与观察。

## 15. 数据可用性审计与前置准入门禁 (G5.1 审计强制补充)

> [!CAUTION] 状态机实现与启用绝对红线
> **在以下 7 项物理数据可用性要求获得完整证据验证前，绝对不得在生产系统中实现或启用该板块拥挤度状态机！**

1. **行业分类版本与代码标准**：
   - 必须锁定唯一的标准分类（如申万 2021 版二级行业分类，共 134 个子行业）；
   - 必须接入分类历史调整变动表（区分 2014 版与 2021 版切换时点），杜绝将当前分类回溯应用到历史引起的时点前瞻偏差（Look-Ahead Bias）。
2. **成分股历史时序与幸存者偏差防护**：
   - 必须具备逐日或逐季度的成分股历史动态权重表（包含已退市、已更名、已转板的历史标的）；
   - 严禁使用静态最新成分股计算历史板块指标，杜绝幸存者偏差（Survivorship Bias）。
3. **日频历史深度与自洽基线**：
   - 滚动 120 日至 3 年历史分位计算，要求全市场各行业至少拥有连续自洽的 750~1250 个交易日日频量价数据；
   - 当前数据库中 `market_daily_snapshot` 仅有 2 条记录，物理数据积累严重不足。
4. **两融与 ETF 衍生数据覆盖真实性**：
   - 行业 ETF 仅覆盖少数热门主题（如芯片、半导体、医药、军工），大量细分二级行业并无对应 ETF；
   - 交易所两融标的池有明确白名单限制，不可将两融余额变化等同于全行业真实杠杆资金。
5. **PIT (Point-in-Time) 时点一致性**：
   - 行业自由流通市值作为分母，其更新依赖上市公司季报、中报、年报与股本变动公告；必须记录披露时间戳（Announcement Date），严禁使用报告期末时间戳（Period End Date）提前计算。
6. **缺失处理与优雅降级规则**：
   - 当行业内发生大面积成分股停牌（例如累计停牌流通市值占比 $> 30\%$）或外部源断流时，状态机必须输出 `CrowdingStatus.UNKNOWN` 或 `DataStatus.EMPTY`；
   - 严禁假设缺失数据为 0，严禁偷填默认值。
7. **数据源合规性与商业授权**：
   - 当前系统的 AkShare 爬虫依赖东财 Web 接口，属于非商业逆向接口，存在结构突变、IP 频控与反爬阻断风险；
   - Tushare Pro 行业成分股历史需要 2000 积分以上高级权限；生产部署须具备合法商业数据授权。
