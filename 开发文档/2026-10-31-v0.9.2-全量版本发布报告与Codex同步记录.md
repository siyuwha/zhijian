### 2. NAS (192.168.3.97) 容器平滑更新指令
由于 Desktop 到 NAS 的 SSH 采用交互密码认证，可通过以下两种方式之一完成生产容器拉起：
- **方式一（飞牛 fnOS Web 界面）**：
  在飞牛私有云 Docker 应用界面，找到 `AI-Trading-System` 项目，点击“检测更新”并确认“重新拉取并重启容器”。
- **方式二（NAS 终端一键更新与打标保留回滚点）**：
  ```bash
  cd /vol1/1000/Docker/AI-Trading-System
  # 标记旧版镜像回滚别名
  docker tag ghcr.nju.edu.cn/siyuwha/zhijian-backend:latest ghcr.nju.edu.cn/siyuwha/zhijian-backend:v0.9.1-rollback 2>/dev/null || true
  docker tag ghcr.nju.edu.cn/siyuwha/zhijian-frontend:latest ghcr.nju.edu.cn/siyuwha/zhijian-frontend:v0.9.1-rollback 2>/dev/null || true
  # 拉取 v0.9.2 镜像并以最小停机时间重启
  docker compose -f docker-compose.nas.yml pull
  docker compose -f docker-compose.nas.yml up -d
  ```
