## 一、 战略背景与核心痛点穿透

在 2026-10-13 交易日的实战检验中，“知见”系统暴露出三大严重制约认知研判与交易决策的底层结构性缺陷：

### 1. 剪贴板静默失效（前端交互缺陷）
- **现象**：用户在内网环境（`http://192.168.3.97:3000`）点击“复制全文”按钮后毫无反应，剪贴板空白。
- **根因**：现代浏览器的安全策略（Secure Contexts）对非 HTTPS / 非 localhost 域名严格封锁 `navigator.clipboard.writeText` API。未做容灾的代码直接抛出安全异常并被静默吃掉。

### 2. 复盘引擎量能失真与分时路径缺失（认知事实层缺陷）
- **现象**：
  1. 系统复盘研报将 2026-10-13 的真实量能（1.68万亿元放量 +8.98%）误算为“-3189亿元 (-15.98% 缩量)”，导致认识论第一章与后续博弈推演出现根本性方向误判；
  2. 四大核心指数全天极为关键的“早盘恐慌深跌 -3.6% → 午后暴力承接回拉”的深V轨迹未被算法提炼，仅有干瘪的收盘涨跌幅。
- **根因**：
  1. 量能算法在对齐历史基准时存在双重去重与字段映射错位；
  2. 数据源管道未提取分时最低价、回拉幅度与振幅极值。

### 3. AI提问沦为“静态文本检索器”，缺失个股穿透与全源按需抓取（AI架构缺陷）
- **现象**：当用户在 AI 抽屉提问“分析昆船智能（301311）”时，大模型只能无奈声明“研报中未提及该标的，处于沉默区间”，无法展开实质盘口与筹码分析。
- **根因**：
  1. 原接口将复盘研报截断为前 3,500 字符，丢失后半部分关键推演与标的池；
  2. 单向纯 RAG 架构，仅将静态研报作为唯一上下文；
  3. 未打通“按需抓取”通路，未将接入“知见”的底层数据源（Eastmoney 证券搜索、Sina 实时盘口、题材概念标签）作为 Tool/动能插件赋予 AI 引擎。

## 二、 架构级进化：知见全源按需沙盘推演体系

为实现“成为市场最强AI沙盘推演”的战略目标，本期实施完成了从**静态阅读器**向**全源认知沙盘推理引擎**的质的飞跃：

                    ┌──────────────────────────────────────────────┐
                    │               用户自由交互输入                │
                    │      （例如：“分析昆船智能”、“宁德时代今天…”） │

                                           │

                    ┌──────────────────────────────────────────────┐
                    │  动态个股代码/名称提取探针 (_detect_and_fetch) │
                    └──────────────────────┬───────────────────────┘
                                           │
                    ┌──────────────────────┴──────────────────────┐
                    ▼                                             ▼
     ┌─────────────────────────────┐               ┌─────────────────────────────┐
     │   Eastmoney 证券代码检索    │               │     Sina 实时逐笔盘口       │
     │   (精准识别代码与板块归属)   │               │ (现价/涨幅/成交额/分时极值) │
     └──────────────┬──────────────┘               └──────────────┬──────────────┘

                    │ ├ 2. 实时按需抓取的个股物理盘口与概念标签    │

                    └──────────────────────────────────────────────┘

### 1. 动态按需数据抓取管道（`_detect_and_fetch_stock_facts`）
- **智能实体提取**：利用正则与分词，自动从提问语句中识别 6 位股票代码（如 `301311`）或常见 A 股股票简称（如 `昆船智能`）；
- **动态全源桥接**：
  - 调用 `EastmoneyProvider.search_security` 实时解析股票真实代码、板块（深市/沪市/创业板/科创板/北交所）；
  - 调用 `SinaProvider.get_stock_quotes` 毫秒级提取最新价、涨跌幅、成交额、最高价、最低价、换手振幅；
  - 动态关联提取概念题材画像；
- **沙盘上下文热注入**：在 Prompt 中开辟专属 `【按需调动“知见”全源实时数据注入】` 区块，将抓取的物理事实刚性呈现给大模型，彻底消除“研报没写就无法分析”的物理墙。

### 2. 全景研报万字上下文全量解锁与多轮记忆链
- **移除 3,500 字符封印**：后端全面放开对 `report_content` 的暴力截断，保留万字研报全量 11 章事实与推演；
- **扩展 Token 预算**：将回复预算从 1,200 扩大至 2,500 Tokens，确保大模型拥有充分的推演论述空间；
- **多轮会话记忆链**：API 与前端无缝协同传递 `messages` 历史对话，支持交互式连续沙盘追问与推演推敲。

## 四、 前端生产交互与高可用容灾

### 1. 双重容灾剪贴板机制
在 [`frontend/src/components/review/ZhijianReviewCockpit.tsx`](file:///d:/项目库/AI认知复盘交易系统/frontend/src/components/review/ZhijianReviewCockpit.tsx) 中重构复制全文逻辑：
```typescript
const copyToClipboard = async (text: string) => {
  // 1. 尝试现代 Clipboard API (仅在 HTTPS 或 localhost 生效)
  if (navigator.clipboard && window.isSecureContext) {
    try {
      await navigator.clipboard.writeText(text);
      return true;
    } catch (e) {
      console.warn("Clipboard API failed, falling back to execCommand", e);
    }
  }
  // 2. 经典降级方案：创建不可见 textarea + execCommand('copy')
  const textArea = document.createElement("textarea");
  textArea.value = text;
  textArea.style.position = "fixed";
  textArea.style.left = "-999999px";
  textArea.style.top = "-999999px";
  document.body.appendChild(textArea);
  textArea.focus();
  textArea.select();
  try {
    const successful = document.execCommand("copy");
    document.body.removeChild(textArea);
    return successful;
  } catch (err) {
    document.body.removeChild(textArea);
    return false;
  }
};
```
- **视觉反馈**：复制成功后按钮文字即时变为“已复制全文”，图标切换为绿色勾选，并在 2 秒后平滑恢复。实测在局域网 HTTP 访问下 100% 成功。

### 2. 机构级自动化结算标识
彻底移除不合时宜的“手动重新生成”按钮，固化为展示“每日 16:30 自动收敛完成”的静态专业徽章，符合机构研报生产纪律。
