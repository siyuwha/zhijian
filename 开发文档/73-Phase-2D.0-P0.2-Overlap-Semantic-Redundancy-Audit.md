## 五、重新定义“语义冗余”的必要条件

当前系统存在的逻辑错误是：
$$\text{High Overlap} \implies \text{Redundant} \implies \text{Fold}$$

本审计正式确立：**判定两个板块标签是否属于“语义冗余（可安全合并/去重）”，必须同时满足以下 6 维约束，缺一不可：**

```text
               【语义冗余判定模型】
                      ┌───────────────┐
                      │  High Overlap │ (充分必要条件之一)
                      └───────┬───────┘
                              │
          ┌───────────────────┼───────────────────┐
          ▼                   ▼                   ▼
┌──────────────────┐ ┌──────────────────┐ ┌──────────────────┐
│ Taxonomy 同层级  │ │ Leader 同一龙头  │ │ Ladder 梯队同构  │
│ (同为概念或行业)  │ │ (同一标杆驱动)   │ │ (高度结构一致)   │
└──────────────────┘ └──────────────────┘ └──────────────────┘
          ▲                   ▲                   ▲
          │                   │                   │
          └───────────────────┼───────────────────┘
                              │
          ┌───────────────────┴───────────────────┐
          ▼                                       ▼
┌──────────────────┐                    ┌──────────────────┐
│ Narrative 同叙事 │                    │ 无独立增量证据   │
│ (交易逻辑同源)   │                    │ (无独特技术催化) │
└──────────────────┘                    └──────────────────┘
```

1. **Taxonomy 层级一致性**：若一个是宏观行业容器（如电力设备），另一个是具体投资主题（如锂电池），**禁止判定为语义冗余**；
2. **Leader 标杆一致性**：两个板块的核心连板高度标杆必须为同一只股票；
3. **Ladder 梯队同构性**：连板天梯结构必须高度重合；
4. **Narrative 叙事同源性**：资金买入驱动逻辑在二级市场语境中没有本质差别；
5. **Temporal 时间同步性**：成分标的的封板时间与启动波段呈现同频；
6. **无独立增量证据（No Independent Catalyst）**：细分题材不具备独立重大技术催化或独立领军标杆。

**结论**：`电池` 与 `锂电池概念` 满足上述 6 维，可判定为近同义冗余；而 `电力设备` 与 `电池` 跨越了 Taxonomy 层级，`电池` 与 `固态电池` 具有不同的 Leader 与独立技术催化，**均绝不满足语义冗余条件**！

### 1. 废除单一百分比规则，升级为 `Multi-Dimensional Semantic Relation Contract`

未来去重判定契约不应是 `overlap > 70% => merge`，而必须是：

```python
class SemanticRelationType(str, Enum):
```
