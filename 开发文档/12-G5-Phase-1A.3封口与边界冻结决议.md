## 二、法定冻结边界清单（8 项铁律边界）

依据最高董事会指示，以下 8 项核心边界即刻进入**绝对冻结状态**，未经正式变更闸门流程，任何 Agent 均不得擅自突破或改写：

1. **D1～D6 状态向量定义冻结**：
   - D1（市场整体）、D2（纯粹广度）、D3（短线情绪与极端生态）、D4（风格偏好）、D5（外部环境）、D6（流动性）之维度划分、权重配置及数学定义保持不变。
2. **D3 双子域语义冻结**：
   - 坚决保持【子域 A：投机高标结构事实】与【子域 B：尾部极端博弈事实】的双子域正交表达；
   - D3 核心得分强制置空（`score = None`），坚决防范任何维度的标量塌缩。
3. **D6 流动性正式列编**：
   - D6 流动性活跃度正式纳入 M1 每日收盘复盘产品全链路与状态向量体系。
4. **缺失值与真实 0 区分铁律**：
   - 指标缺失时显式标明为 `None` / `'--'`，严禁使用默认值伪造；
   - 真实数值 0（如 0 炸板率、0 跌停）严格展示为 `0` 或 `0.0%`，继续保持严格判空与区分。
5. **复盘数据链路与前端展示验收冻结**：
   - 后端数据抓取、计算、持久化、REST API，以及 Next.js 列表与六维状态看板，正式进入“已验收（Accepted）”稳定态。
6. **历史缺陷闭环与注销**：
   - 1A.3 阶段由独立红队检出的 3 项 P1 级缺陷（指数偷填0、真实0炸板率混淆、脏数据白屏风险）与 2 项 P2 瑕疵，正式确认为“已彻底修复并关闭（Closed）”。
7. **数据库 Schema 刚性保护**：
   - 数据库 Schema 保持完全稳定，不因 1A.3 及后续日常展示需求做任何未授权变更。
8. **后续语义问题严格受控（变更闸门原则）**：
   - 后续任何模块（包括 M2、M3、策略层等）在消费过程中若发现状态语义问题，**一律不得直接修改 1A.2 / 1A.3 已冻结的代码与配置**，必须单独发起正式技术设计单，并走四权分立变更闸门审批！
