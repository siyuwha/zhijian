### 1.2 层级职责与约束

| 层 | 职责 | 边界约束 |
|---|------|---------|
| **Presentation** | UI 展示、用户交互、数据可视化 | 不含业务逻辑 |
| **API** | 路由、参数校验、请求/响应格式化 | 不含业务逻辑，只做协议转换 |
| **Service** | 业务编排、流程控制 | **编排层，不应演变为承载全部业务逻辑的"大 Controller"** |
| **Cognition** | 市场状态计算、认知接口预留 | 独立架构层，保持独立领域职责 |
| **Strategy** | 策略管理、选股引擎 | 独立架构层，AI 自主 + 用户自定义双模式 |
| **Risk** | 风险评估、约束检查 | 独立架构层，不可被绕过 |
| **Human** | 人的决策入口、反馈/验证通路 | 独立架构层，AI 输出必须经过 Human |
| **Data** | 数据采集、Provider 管理、质量追踪 | 上层依赖 Capability，不依赖具体 Provider |
| **Persistence** | 数据存储、查询、迁移 | SQLite + ORM，Schema 版本化管理 |

> **Core Layers 之间通过明确接口协作，不形成强耦合。各层保持独立领域职责。**

                               ├→ Cognition Layer (市场状态计算)

M6 选股流（可随时触发）
  Data Layer → Cognition (市场状态) → Strategy (选股引擎)

from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum

class DataQuality(Enum):
    FULL = "full"
    PARTIAL = "partial"
    FAILED = "failed"

@dataclass
class DataResult:
    """统一数据返回结构"""
    data: Any
    quality: DataQuality
    provider: str
    timestamp: datetime
    fallback_used: bool = False

class IndexQuoteCapability(ABC):
    """A股指数行情能力"""
    @abstractmethod
    async def get_index_quotes(self, codes: list[str]) -> DataResult: ...

class StockQuoteCapability(ABC):
    """A股个股行情能力"""

### 2.3 Provider 注册与降级

```python
# backend/app/data/registry.py

class ProviderRegistry:
    """
    Provider 注册中心
    - 管理 Capability → Provider 映射
    - 支持 Primary / Fallback 降级链
    - 按配置加载，运行时可切换
    - 新增 Provider 不修改上层业务
    """
    
    async def resolve(self, capability: str) -> DataResult:
        """按降级链依次尝试 Provider"""
        entries = self._providers[capability]
        for entry in entries:
            try:
                result = await entry.provider.execute()
                if result.quality != DataQuality.FAILED:
                    return result
            except Exception as e:
                logger.warning(f"Provider {entry.name} failed: {e}")
                continue
        return DataResult(data=None, quality=DataQuality.FAILED, ...)
```

### 2.6 自定义接口兼容要求

系统必须具备持续接入不同数据接口的能力：

1. 标准第三方数据接口
2. 不同协议的数据接口
3. 不同返回格式的数据接口
4. 自定义数据接口
5. 用户未来自行增加的 Provider
6. 不同认证方式及调用限制的接口

> **Capability 标准化，上层业务与具体接口解耦；Provider / Adapter 提供标准扩展接口，允许新增自定义 Provider，而无需修改 Cognition、Strategy、Review 等核心模块。**

#### 3.1.3 市场状态计算框架（M1.4）

```python
# backend/app/cognition/market_state.py

class MarketStateConfig(BaseModel):
    """市场状态指标配置 — 可动态调整"""
    indicators: list[IndicatorConfig]
    
class IndicatorConfig(BaseModel):
    name: str
    enabled: bool
    weight: float
    source: str           # 数据来源 Capability
    compute_func: str     # 计算函数名
    thresholds: dict      # 阈值配置

class MarketStateComputer:
    """
    市场状态计算引擎
    - 指标体系通过配置定义，运行时可调整
    - 新增/删除指标不需要修改核心代码
    - 初始指标集合、权重、阈值在 G4 确定
    """
    
    async def compute(self, market_data: MarketSnapshot) -> MarketState:
        results = []
        for indicator in self.config.indicators:
            if not indicator.enabled:
                continue
            value = await self._compute_indicator(indicator, market_data)
            results.append(value)
        
        composite = self._weighted_sum(results)
        label = self._classify(composite)
        return MarketState(
            indicators=results,
            composite_score=composite,
            state_label=label, ...
        )
```
