## 二、法定冻结边界清单（8 项铁律边界）

依据最高董事会指示，以下 8 项核心边界即刻进入**绝对冻结状态**，未经正式技术设计单与四权分立变更闸门流程，任何 Agent 均不得擅自突破或改写：

1. **隔夜外盘解析与清洗规范冻结**：
   - 纳斯达克 (`ixic`)、道琼斯 (`dji`)、标普500 (`inx`)、富时中国A50期货 (`CHA50CFD`)、恒生指数 (`hangseng`) 5 大核心标的点位与涨跌幅标准浮点数清洗规范冻结；
   - 缺失值显式保持为 `None`，前端渲染为 `'--'`，严禁填 `0.0` 伪造假平盘。
2. **前日 M1 状态向量继承与抗标量塌缩铁律冻结**：
   - M2 盘前简报消费昨日复盘时，必须直接提取持久化的 M1.4 纯净状态向量，严禁二次重算或篡改状态；
   - D3 核心得分全链路（后端 -> API -> 前端）坚决保持为 `None`；
   - Sub-A（投机高标结构）与 Sub-B（尾部极端博弈）在看板中必须正交独立并列呈现，严禁做单一平均标量压缩。
3. **早盘 4 维客观观察推演与零交易信号铁律冻结**：
   - 4 维推演（竞价量能比值、高标溢价、尾部极端释放修复、外盘扰动映射）严格限定为开盘前后的客观物理观察维度；
   - 严禁产生任何买入、卖出、加仓、清仓等诱导性投资建议或主观买卖信号；
   - 前后端全链路全看板逐项强制绑定“客观观察维度提示，非买卖建议”免责声明。
4. **前端百分比量纲自适应规范冻结**：
   - 连板晋级率、真实炸板率等底层小数比例统一通过 `formatRatioToPct` 安全自适应归一化并乘以 100 输出（如 33.3%、25.0%）；
   - 杜绝缩放 100 倍与上下叙事相矛盾的展示缺陷。
5. **数据库 Schema 零变更刚性保护冻结**：
   - 严格复用现有 SQLite `premarket_briefing` 数据模型，零 Schema 变更、零结构迁移，统一通过强类型 JSON 字段序列化存储。
6. **零 Mock 残留与生产级交互冻结**：
   - 彻底清除 2023 年旧 mock 假数据与废弃死代码，前后端 100% 绑定真实 API 与数据源；
   - Next.js 生产构建 (`next build`) 12/12 页面 100% 编译成功，0 类型报错，0 语法警告。
7. **1B 阶段红队发现缺陷正式注销（Closed）**：
   - 1 项 P1 级缺陷（前端晋级率/炸板率量纲放大失真）与 2 项 P2 瑕疵（空安全兜底、契约补齐 dimensions）确认为彻底清零并闭环注销。
8. **跨阶段消费严格受控（变更闸门原则）**：
   - 后续阶段（包括 M3 集合竞价决策、策略层等）消费盘前简报数据时，**一律不得随意修改 1B 已冻结的 API 与数据契约**，必须单独发起技术设计单，走四权分立变更闸门。
