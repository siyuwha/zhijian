## 一、本次全量升级核心模块清单

### 1. 模拟交易统计与页面异常防护闭环 (T01 / T04-01)
- **逐笔平仓腿收益核算**：引入移动加权平均成本法，完整核算每一笔卖出交易腿的实现盈亏、胜负样本；
- **动态胜率与盈亏比**：彻底废弃历史固化的 `payoff_ratio: 1.8`，根据真实平仓样本动态计算 `win_rate`、`closed_leg_win_rate` 与 `payoff_ratio`；
- **409 异常防线**：拦截“无成本卖出”与“超卖”异常，阻断脏数据污染统计，返回结构化 409 提示；
- **请求逆序竞态防护**：前端引入 `reqSequenceRef` 序列锁，确保迟到的旧响应绝不覆盖最新状态；
- **页面异常容灾**：非 JSON 500、空数据、null 字段场景平滑降级为 `--`，并常驻错误警示横幅；
- **回归与契约测试**：`test_simulation_stats.py` 13 项契约测试通过；隔离路由 409 透传验证通过。

### 2. 通达信 (TDX) 原生行情直连与高可用链路
- **毫秒级原生直连**：引入 PyTDX 协议直连券商主站，原生支持五档快照、分时走势与历史 K 线；
- **高可用连接池**：实现 `tdx_client.py` 自动选站、连接池复用、心跳保活与超时断线重连；
- **双轨降级与调度**：`tdx_provider.py` 与 `eastmoney.py` 协同，当 TDX 异常时自动降级至备用行情源，保障生产连续性；
- **数据调度统一**：在 `data/service.py` 与 `data/capabilities.py` 注册能力集，统一提供标准化行情协议。

### 3. 极光驾驶舱 (Aurora Cockpit) 交互与接口
- **实时看板优化**：`AuroraCockpitView.tsx` 深度对齐行情直连数据，优化轮询与盘中监控体验；
- **前端 API 统一**：`frontend/src/lib/api.ts` 对齐最新行情端点与数据结构。

### 4. 架构规范与 NAS 部署优化
- **部署脚本防卡死改造**：重构 `deploy_nas.sh`，优先拉取云端 GHCR 预编译镜像，杜绝 NAS 本地 Next.js 编译引发的假死与 OOM；
- **多 Agent 分工规范 (`AGENTS.md`)**：明确 Work（需求与版本定义）、Antigravity（实施自检）、Codex（独立审查）法定职责；
- **版本单一真实源 (SSOT)**：正式确立 SemVer 规则，版本号由 Work 指定并在发布时联动更新 3 件套，Codex 严格对齐基准，严禁自创新版本号。
