## 三、五大指标深度剖析与端到端闭环

### 3.1 指标 1：Schema Compliance (100%)
在升级不可变 `PromptSpec v1.1.0` 嵌入显式 JSON 键名与类型说明后，`deepseek-flash` 表现出极高的指令遵从度：
- JSON 解析成功率：**100%** (5/5)；
- 必备字段齐全率：**100%** (5/5)；
- 键名严格匹配率：`target_date`, `hypothesis_type`, `expected_assertions`, `invalidation_assertions` 等字段 100% 吻合。

### 3.2 指标 2：Validator Compliance 与 VR-07 刚性防御
- **4 条 Proposal 顺利全通**（`trial_001`, `trial_003`, `trial_004`, `trial_005`）：全部满足白名单、标的代码、时序及反向证伪红线规则；
- **1 条 Proposal 被 VR-07 精准拦截**（`trial_002_2026-09-28`）：
  - **触发原因**：模型在 `explanation` 字段中写了一句防御性免责声明：“*本推演仅针对...客观路径与证伪边界，不涉及任何个股推荐、买卖指令、加减仓建议或目标价。*”
  - **系统判定**：因命中了交易黑名单词 `'目标价'`，`ProposalValidator` 刚性阻断，抛出 `VR-07_PROHIBITED_TRADING_ADVICE`，坚决拒绝其进入 AST 编译！
  - **工程结论**：这证明 `ProposalValidator` 的防御层完全没有被大模型“好心免责”绕过，刚性防御机制真实、严格、可靠。

### 3.3 指标 3：Fact Boundary & Temporal Causality (时序因果)
- 5 个历史日切片中，输入给大模型的 Prompt 仅包含 T 日 15:00 的收盘客观统计；
- 任何关于 `target_date` 的未来数据均未进入 Prompt，`target_date > observation_date` 100% 成立；
- Prompt SHA-256 唯一指纹与原始事实切片双向锚定。

### 3.4 指标 4：AST Compilation & Falsification 引擎端到端仲裁
4 条通过校验的提案成功转换为内存收窄 AST `MarketHypothesisDefinition`，并挂载真实历史 $T+1$ 收盘事实，由 `FalsificationEngine` 执行客观波普尔仲裁：

```text
Proposal 1 (2026-09-26 -> 2026-09-28)
  -> 假说：预期市场弱修复，连板高度保持在4板及以上，跌停<30家
  -> T+1 事实：09-28 恐慌暴跌，全A跌停激增至56家，触发 inv_3
  -> 仲裁结论：🔴 FALSIFIED（客观成功证伪，反向红线生效）

Proposal 3 (2026-09-29 -> 2026-09-30)
  -> 假说：预期多项指标全面修复 (AND 逻辑)
  -> T+1 事实：3 项满足，1 项未达标，未触碰证伪红线
  -> 仲裁结论：⚪ UNCONFIRMED（未达全部证实标准，亦未证伪）

Proposal 4 (2026-09-30 -> 2026-10-01)
  -> 假说：预期节前震荡平稳，涨跌幅与跌停维持低位
  -> T+1 事实：5 项预期指标全部达成，零证伪断言触发
  -> 仲裁结论：🟢 CONFIRMED（假说被客观事实证实）

Proposal 5 (2026-10-01 -> 2026-10-08)
  -> 假说：节后首日推演
  -> T+1 事实：历史数据库仅收录至 2026-10-01，10-08 数据缺失
  -> 仲裁结论：⏳ PENDING（客观缺数，杜绝伪造）
```

这是系统历史上**第一次看到“真实 LLM 提议 → 校验器准入 → AST 编译 → 未来事实灌入 → 证伪引擎客观裁决”全链路真实走通**！
