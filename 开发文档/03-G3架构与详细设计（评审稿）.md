### 1.2 层级职责

| 层 | 职责 | 边界 |
|---|------|------|
| **Presentation** | UI 展示、用户交互、数据可视化 | 不含业务逻辑，只做展示和用户输入 |
| **API** | 路由、参数校验、请求/响应格式化 | 不含业务逻辑，只做协议转换 |
| **Service** | 业务编排、流程控制 | 调用 Core Layers 和 Data Layer 完成业务 |
| **Cognition** | 市场状态计算、认知接口预留 | 独立架构层，Phase 1 定边界，G3 后续扩展 |
| **Strategy** | 策略管理、选股引擎 | AI 自主 + 用户自定义双模式 |
| **Risk** | 风险评估、约束检查 | 独立于 Strategy，不可被绕过 |
| **Human** | 人的决策入口、反馈/验证通路 | AI 输出必须经过 Human 才能执行 |
| **Data** | 数据采集、Provider 管理、质量追踪 | 能力稳定 Provider 可替换 |
| **Persistence** | 数据存储、查询、迁移 | SQLite + ORM，后期可迁移 |

### 1.3 核心数据流

```text
交易日生命周期数据流：

08:00 盘前
  CLS/Sina Providers → Data Layer → PremarketService → 盘前简报 → DB → Web

09:15-09:25 竞价
  THS/Sina Providers → Data Layer → AuctionService → 竞价报告 → DB → Web

09:30-15:00 盘中
  Sina/East Providers → Data Layer → MonitorService → 实时观察 → WebSocket → Web

15:30 收盘
  Baostock/THS/Sina → Data Layer → DailyReviewService
                                       ├→ Cognition Layer (市场状态计算)
                                       ├→ 复盘报告 → DB → Web
                                       └→ Strategy Layer → 候选池 → DB → Web

M6 选股流（可随时触发）
  Data Layer → Cognition (市场状态) → Strategy (选股引擎)
    → Risk (约束检查) → Human (确认) → 候选池 → DB

M8 前向模拟流
  Strategy → 交易计划 → Risk → Human → SimulationService
    → 模拟执行 → 市场结果对比 → 复盘反馈 → Cognition
```

```python
# backend/app/data/capabilities.py

from abc import ABC, abstractmethod
from dataclasses import dataclass
from enum import Enum

class DataQuality(Enum):
    FULL = "full"
    PARTIAL = "partial"
    FAILED = "failed"

@dataclass
class DataResult:
    """统一数据返回结构"""
    data: Any
    quality: DataQuality
    provider: str           # 实际提供数据的 Provider 名称
    timestamp: datetime
    fallback_used: bool = False

class IndexQuoteCapability(ABC):
    """A股指数行情能力"""
    @abstractmethod
    async def get_index_quotes(self, codes: list[str]) -> DataResult:
        """获取指数行情（沪深创科等）"""
        pass

class StockQuoteCapability(ABC):
    """A股个股行情能力"""

        """批量获取个股行情"""
        pass

class LimitUpCapability(ABC):
    """涨停池数据能力"""
    @abstractmethod
    async def get_limit_up_pool(self, date: str) -> DataResult:
        """获取涨停池（含情绪、连板、题材归因）"""
        pass

class OvernightCapability(ABC):
    """隔夜外盘数据能力"""
```

### 2.3 Provider 注册与降级

```python
# backend/app/data/registry.py

class ProviderRegistry:
    """
    Provider 注册中心
    - 管理能力→Provider 的映射关系
    - 支持 Primary/Fallback 降级链
    - 按配置文件加载，运行时可切换
    """
    
    def __init__(self, config: DataConfig):
        self._providers: dict[str, list[ProviderEntry]] = {}
        # config 示例:
        # index_quote:
        #   primary: sina
        #   fallback: [eastmoney]
        # limit_up:
        #   primary: tonghuashun
        #   fallback: [eastmoney]
    
    async def resolve(self, capability: str) -> DataResult:
        """按降级链依次尝试 Provider"""
        entries = self._providers[capability]
        for entry in entries:
            try:
                result = await entry.provider.execute()
                if result.quality != DataQuality.FAILED:
                    return result
            except Exception as e:
                logger.warning(f"Provider {entry.name} failed: {e}")
                continue
        return DataResult(data=None, quality=DataQuality.FAILED, ...)
```

#### 3.1.3 市场状态计算框架（M1.4）

```python
# backend/app/cognition/market_state.py

class MarketStateConfig(BaseModel):
    """市场状态指标配置 — 可动态调整"""
    indicators: list[IndicatorConfig]
    
class IndicatorConfig(BaseModel):
    name: str           # 指标名称
    enabled: bool       # 是否启用
    weight: float       # 权重
    source: str         # 数据来源能力
    compute_func: str   # 计算函数名
    thresholds: dict    # 阈值配置（如 {"strong": 80, "weak": 30}）

class MarketStateComputer:
    """
    市场状态计算引擎
    - 指标体系通过配置文件定义，运行时可调整
    - G1 不冻结具体指标集合
    - 新增/删除指标不需要修改核心代码
    """
    
    def __init__(self, config: MarketStateConfig):
        self.config = config
        self._computers = {}  # name -> compute function
    
    async def compute(self, market_data: MarketSnapshot) -> MarketState:
        results = []
        for indicator in self.config.indicators:
            if not indicator.enabled:
                continue
            value = await self._compute_indicator(indicator, market_data)
            results.append(value)
        
        composite = self._weighted_sum(results)
        label = self._classify(composite)
        return MarketState(
            indicators=results,
            composite_score=composite,
            state_label=label,
            ...
        )
```

### 7.3 任务调度框架

```python
# backend/app/tasks/scheduler.py

from apscheduler.schedulers.asyncio import AsyncIOScheduler

class TaskScheduler:
    def __init__(self, calendar: TradingCalendar):
        self.scheduler = AsyncIOScheduler()
        self.calendar = calendar
    
    def setup(self):
        # 盘前简报 - 每天 08:00
        self.scheduler.add_job(
            premarket_task, 'cron', hour=8, minute=0,
            misfire_grace_time=300
        )
        # 竞价观察 - 每天 09:26
        self.scheduler.add_job(
            auction_task, 'cron', hour=9, minute=26,
            misfire_grace_time=60
        )
        # 盘中监控 - 盘中每 60 秒
        self.scheduler.add_job(
            monitor_task, 'interval', seconds=60
        )
        # 收盘复盘 - 每天 15:35
        self.scheduler.add_job(
            daily_review_task, 'cron', hour=15, minute=35,
            misfire_grace_time=300
        )
        # 所有任务内部自行检查 is_trading_day
```
