# Trading AI OS 认知沉淀与数据源清单

> 用途：Trading AI OS（Legacy）已中止，本文件沉淀其中可继承的核心认知与数据源，作为 知行交易 新系统与 Hermes 记忆迁移的参考底稿。
> 生成：2026-09-15，基于 Hermes 长期记忆梳理，非代码文档。

## 一、认知沉淀（第一类，保留）

### 交易哲学
- 跟量化节奏，不跟游资——等波动打出后低吸，跟差价不格局。
- 竞价模式：倍量首板 / 竞价高开低走（三关：板块共振 → 企稳 → 回踩）。
- 止损单委托价必须是市价（8/6 教训：挂单市价成交才可靠）。

### 规则与经验
- **LTV 规则（逻辑-标的一致性验证）**：买入前必须确认逻辑与标的一致——看好 X 须查 X 占公司收入比例，无实证一票否决。绿盟案例：以为买 AI 应用实际是网安股，割肉次日 +18.9%。
- **板块分析框架**：按 reason_type 归因——行业是出生证，逻辑才是涨因。
- **候选池分层**：A≥75 / B 50-74 / C<50，仅 B 级有参考；R0/R1 冰点日常 0 候选（过滤过严属正常）。
- **行为假设（勿固化为规则）**：追高站岗 / 恐慌割 / 止损反弹循环；用户也会打板（炸板次日必走）。
- **Learning Independence 原则**：经验沉淀 = Case→Experience→Suggestion，不是 Case→Hard Rule→Auto-Enforce；Future Reference 替代 Future Rule，保持 AI Suggests → Human Approves。
- **盯盘脚本铁律**：is_trading_time + 价>0 双查（东财盘外价 0 误触发，8/24 教训）。
- **验收原则**：用 15:15 后结算数据验证，不用盘中数据；验收 = 生产实证（真实 cron 产物），非单测。

### 交易纪律
- 板块共振首日 / 回踩；持仓 ≤2；R0 空仓；禁连续加速后的情绪追高；候选池仅输入。
- 量化层职责：板块共振 + 身位前 2 + 题材纯 + 位置，跌买涨卖；认知层职责：分辨量能原因（语义归因），量化层负责制造振幅套利。
- 操作建议须精确股数 + 写清"不是清仓"（绿盟全清教训）；埋伏提醒降级为预警（不说"买入"），执行前验证实时价；条件单挂单等成交。
- 选股范围：300 创业板可做，不再因 300 代码自动排除；仍需按题材共振、位置、流动性与 20cm 波动风险逐票评估；科创 688、北交所是否纳入需另行确认。

### 复盘与报告范式
- 复盘图先读 snapshots/{date}/daily_review.md。
- Daily Review 范本（2026-08-21 / 08-24）：市场总览、情绪、主线/资金、Cognition、赚钱风格、校正、明日 IF/THEN/失效、风险/数据质量；须可审计、显式降级/冲突；UNKNOWN≠看空，Ceiling≠实际仓位，WATCH/selected_symbols≠买入。
- 早报格式：隔夜/消息/昨日/持仓/观察/一句话。
- 对账机制：复盘先对前日账，次日市场 = 真值；Gemini 复验沉淀台账。
- 竞价观察 15:45 台账：auction_gap_weak_ledger。
