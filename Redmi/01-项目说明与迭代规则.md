# A股行情透视认知交易OS — 项目说明与迭代规则

## 项目定位
围绕 A 股行情，构建“行情数据—市场结构—交易决策—复盘认知—系统迭代”的闭环知识框架。

## 目录结构

| 目录 | 定位 | 维护频率 |
|---|---|---|
| 00-项目总览 | 项目说明、使用规则、版本与迭代约定 | 项目结构变化时更新 |
| 01-行情数据 | 行情指标、数据字段、数据质量规则 | 有新数据源或指标时更新 |
| 02-市场结构 | 行业、风格、资金、波动等结构层分析 | 每周复盘后更新 |
| 03-交易策略 | 策略假设、触发条件、仓位与风控 | 策略验证或失效时更新 |
| 04-复盘与认知 | 交易复盘、认知偏差、决策记录 | 每次复盘后更新 |
| 05-市场与情绪 | 情绪指标、资金行为、市场叙事 | 每日/每周更新 |
| 06-工具与自动化 | 脚本、数据拉取、可视化、自动化工具 | 工具或流程变化时更新 |
| 07-文档与模板 | 可复用文档模板、标准格式 | 模板升级时更新 |
| 08-后续优化方向 | 待优化需求、已知局限、下一步计划 | 每次迭代后更新 |

## 迭代规则

1. 所有新内容先落进对应目录，再更新本文件说明。
2. 复盘必须落到“可执行的策略调整”或“明确的认知修正”，不写空话。
3. 策略失效时，在 03-交易策略 标注失效原因与时间，再迁移到 08-后续优化方向。
4. 工具与自动化脚本需附使用说明和输出位置。
5. 长任务执行时保持连续推进，完成后统一提交，避免中途卡住。
